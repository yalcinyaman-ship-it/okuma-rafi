# Timaş Çocuk — Dijital Okuma Rafı

Tek dosyalık statik site. `index.html` her şeyi (logo, yazı tipi stili, kod) içinde taşır.

## Yayına alma (GitHub Pages)
1. GitHub'da yeni bir depo açın (ör. `okuma-rafi`).
2. Bu klasördeki `index.html` ve `README.md` dosyalarını yükleyin.
3. Settings → Pages → Branch: `main` / `root` → Save.
4. Birkaç dakika sonra site `https://KULLANICIADI.github.io/okuma-rafi/` adresinde açılır.

## Güncelleme
Düzeltmeler sonrası verilen yeni `index.html` dosyasını depodaki eskisinin üzerine yükleyin (Add file → Upload files). Pages otomatik yenilenir.

## Not
Drive klasörünü canlı okumak için Google Drive API anahtarı gerekir; bu sürümde örnek veri ve "PDF ile dene" kullanılır.
